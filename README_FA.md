# راه‌اندازی SMOKEBET نسخه ۲

## نیازمندی
- Node.js نسخه ۲۰ یا جدیدتر
- اتصال اینترنت برای نصب بسته‌ها و (در صورت فعال‌سازی) ارسال ایمیل
- این نسخه از SQLite برای ذخیره اطلاعات استفاده می‌کند.

## نصب و اجرا
1. فایل `.env.example` را به `.env` تغییر نام بده.
2. مقادیر `SESSION_SECRET`، `ADMIN_USERNAME` و `ADMIN_PASSWORD` را تغییر بده.
3. در ترمینال، داخل پوشه پروژه اجرا کن:
   ```bash
   npm install
   npm start
   ```
4. در مرورگر برو به `http://localhost:3000`.

## مدیر
با نام کاربری و رمز عبوری که در `.env` تعیین کرده‌ای وارد شو. سپس تب «مدیریت» برایت نمایش داده می‌شود.
**اگر رمز مدیر را بعد از ساخته‌شدن دیتابیس عوض کردی، کاربر مدیر موجود خودکار تغییر نمی‌کند.** برای نصب تازه، پوشه `data` را قبل از اجرا پاک کن.

## ایمیل مدیر (اختیاری)
برای ارسال اعلان ثبت‌نام و پیش‌بینی، اطلاعات SMTP را در `.env` وارد کن. ایمیل‌ها فقط شامل نام کاربری، شماره تماس و اطلاعات پیش‌بینی‌اند؛ رمز عبور هرگز ایمیل یا در گزارش نمایش داده نمی‌شود.

## امنیت و حریم خصوصی
- رمزهای عبور با bcrypt هش می‌شوند؛ رمز خام ذخیره یا برای مدیر ارسال نمی‌شود.
- از رمز قوی و منحصربه‌فرد برای حساب مدیر استفاده کن.
- برای انتشار عمومی، حتماً HTTPS، مقدار تصادفی و طولانی برای `SESSION_SECRET`، پشتیبان‌گیری امن و سیاست حریم خصوصی اضافه کن.
- این پروژه یک نمونه پایه است و پیش از استفاده عمومی باید بازبینی امنیتی و تست شود.
- شماره تماس اطلاعات شخصی است؛ فقط با اطلاع و رضایت کاربر جمع‌آوری و نگهداری کن.

## محدوده محصول
این پروژه فقط برای پیش‌بینی سرگرمی با امتیاز مجازی ساخته شده است؛ بدون پول واقعی، درگاه پرداخت، جایزه نقدی یا تسویه مالی. مسابقات اولیه نمونه هستند و داده زنده نیستند.
